## What v0.5.7 changes strategically
### Research ingestion
Marketplace/search/review feeds can be resumed through explicit cursor/checkpoint metadata while the system remains conservative about source completeness.

### Causal interpretation
Experiment review now understands cluster, geo, CUPED and sequential design context instead of treating every outcome as an independent two-proportion test.

### Local-language copy
Terminology consistency becomes a formal release invariant across Listing fields and Host authoring, reducing silent naming drift between title/highlights/FAQ/etc.

### Production handoff
Surface-native decisions and compiled platform-pack provenance are now frozen into Provider Jobs with contract hashes, so an execution provider receives the same production authority that was approved upstream.

### Photography
Prelight is now an explicit bridge between conceptual CMF strategy and repeatable capture. Exposure ratio, polarization state and cross-shot color consistency are measured/tested rather than stylistically guessed.
