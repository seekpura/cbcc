## What v0.5.6 changes strategically
### Research
Research can now arrive through explicit adapters and incremental batches. Strategy can distinguish real research change from ingestion duplication/version change and refresh only affected layers.

### Experiment / incrementality
Post-hoc p-value is no longer the first experiment interpretation. Design readiness includes assignment, balance, MDE/power and interference/contamination context. Marginal contribution can also be summarized by supplied segment/cohort, with no automatic heterogeneity claim.

### Final Copy
The host/model can now consume Runtime author/revision tasks and return actual new versions. Runtime then re-runs hard checks and keeps release authority separate from generation authority.

### Surface production
Native content strategy now has an executable production layer per surface. The same upstream message can reuse a product master while still requiring a different crop/composition/edit/script/CTA contract.

### Photography / CMF
CMF is now a lighting-engineering input at the shot level. Lighting WHY is not just `85mm / soft light / 5200K`; it explains how the supplied material/finish must be rendered to answer the asset's purchase question truthfully.
