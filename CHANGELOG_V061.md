# v0.6.1 — Hard Delivery Contract + Seven First-Class Tools + Responsive HTML

## Why this release exists
v0.6.0 had deep strategy/creative capability, but a real plugin run showed that several requirements remained advisory rather than materialized: evidence-grade semantics drifted, RACE used the wrong project definition, culture/intersectionality and inclusive-photography fields were not guaranteed in the delivery, platform execution/attribution fields were incomplete, and the seven reference-agent responsibilities were not all exposed as first-class tool contracts.

## Capability changes
- Project-authoritative RACE is now **Research → Action → Communication → Evaluation**.
- A/B/C evidence authority is hard-bound: A=test/cert/reproducible measurement; B=supply-chain/formula/mechanism; C=subjective/pending and never a hard claim.
- Information lock: audit → max 10 questions → explicit assumptions → continue.
- Nine-section FULL delivery contract is machine materialized as `DELIVERY_CONTRACT.json`.
- Platform content rows now carry dimensions/duration/cover/subtitles/music-rights/traffic/CTA/landing/UTM-equivalent attribution/localization checks.
- Culture layer now materializes intersectionality plus a dedicated culture-adaptation checklist.
- Photography contract now includes role-based color/contrast, CCT/WB, key:fill, soft/hard logic, deep-skin exposure bracket/reflector/diffusion, hair/body/age/disability and AI-bias controls.
- Budget/cycle tradeoffs explicitly protect P0/P1 and cut duplicate/decorative P2 first.
- Output self-check materializes fabrication/WHY/culture/compliance/metric/assumption checks.

## Seven first-class tools
`runtime/cbcc/tools/seven_agent.py` and `toolkits/11_seven_agent_contracts/` expose:
1. Market Research
2. Product Strategy
3. Listing Creative
4. Product Image
5. Product Video
6. Advertising Optimization
7. Review Analysis

Image remains dynamic rather than copying the reference project's fixed nine-image quota. Ads returns P0/P1/P2 + attribution/incrementality boundary. Review adds eight-class attribution, misunderstanding detection, fixability, positive selling-point ranking, exact reconciliation and local revision routes.

## Human delivery
Every strategy materialization now includes `MASTER_STRATEGY_CN.html`; every project delivery ZIP includes a responsive offline `index.html` for desktop/mobile review while MD/JSON remain the editable authorities.
