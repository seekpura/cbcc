# Project-Authored HTML Delivery — Stable Interaction Floor

“Project-authored” 不再表示每次重写全局 HTML 壳。对 FULL / 高密度商品项目，先继承 v0.6.36 已验证的 SaaS 交互底座，再让当前项目作者化真实内容结构。

## Stable floor
- primary routes 只投影当前项目真实存在的对象；没有内容的 route 不出现；
- 正常浏览一次只激活一个一级 `.page`；
- module subviews / asset lenses 保留局部切换；
- 资产库进入独立 `asset/<id>` 详情 route；
- search / copy / responsive / print-PDF projection 保留；
- HTML 内直接包含核心正文和生产对象。

## Project-authored layer
Agent 可以动态决定：对象名称/顺序/分组、首页重点、模块内部视图、Portfolio 策展、比较方式、局部 Inspector/Drawer、视觉主题、CMF、信息密度与 responsive 细节。不同项目可以明显不同，但不通过删除成熟基础交互来制造“不同”。

禁止把 FULL 项目做成：
- 一条超长单页；
- 固定 card-grid dashboard；
- 只有 Project Object Switcher 的薄壳；
- 运营摘要替代完整业务对象；
- 资产摘要后要求用户去文件夹找 Design Card / Prompt / Production。

运营执行是有真实 operator artifacts 时出现的增量 route。七工具、九域、Runtime/Gate/hash 没有固定页面权，但其当前相关业务产物必须在合适工作面直接可用。

平台 Gallery/Video 容量只限制 Live Activation Set，不限制 Asset Universe。多 Hero、多广告、PDP/A+、详情、Social/Creator/UGC、Video、Test/Rotation 必须按独立商业/创意假设保留，不能因为 `max_images=9` 被截成 9 个总资产。
