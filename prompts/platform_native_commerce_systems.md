# Professional Prompt — Platform-native Commerce Systems

For each target platform and surface, transform the shared Strategy Authority into the platform's native decision sequence. Do not copy the same headline/script across TikTok Shop, Shopee, Amazon and DTC by default.

Output:
- entry user state,
- native hook logic,
- message/beat sequence,
- copy density,
- proof placement,
- offer/CTA role,
- creator/UGC role if applicable,
- reuse vs new-production decision,
- metric tied to the surface job,
- WHY.

Platform policy constraints remain separate authority and must be respected; platform-native style must never justify claim inflation.
