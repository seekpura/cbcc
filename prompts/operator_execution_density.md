# Operator Execution Density — optional surface, not global IA

Operator-ready delivery means actions are concrete when actions are relevant. It does **not** mean every project must have an Operator Dashboard, Launch Board, P0/P1/P2 homepage or a fixed set of queues.

When an operator action is useful, make it exact: target object, action/change, what stays frozen, completion standard and decision rule. Place it where it best fits the current project interface.

Do not inject an operator section automatically into `index.html`. Do not let statuses, queues or release badges replace strategy, Listing, creative curation, asset production depth or evidence.

The same underlying action may appear inside an asset Inspector, Listing field workspace, campaign test object, economics decision, review-routing object or another project-specific surface. The interface is authored from the current project rather than from this prompt.

Ask or block only for missing inputs that would force factual invention, unsafe publication or economically unjustified spend. Normal creative/layout/product-presence/copy-render decisions remain the Agent's job.
