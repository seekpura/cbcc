# FULL Commercial Depth + Host-Native Materialization Authority — v0.6.47

## Highest current precedence
FULL 商业交付不能用“标题存在 / 布尔值为 true / 文件数量够多”证明完成。无论走本地 Runtime，还是 ChatGPT Skills-only / Host-native 路径，最终必须物化同一套商业对象、同一深度合同和同一语言合同。

**Host-native FULL Materialization Contract = Runtime Export Contract.**

如果 Host 无法调用本地 Python Runtime，不得因此缩成自定义短报告、9张 Gallery 包或一份 index.html。Host 使用当前可用文件/代码能力自行物化同等对象；无法物化的对象明确标 `MISSING_INPUT / TO_VERIFY / NOT_ACTIVE`，而不是静默删除。

## 1. 信息审计与产品事实
先做信息完整度、最多10个关键确认问题、明确假设、假设与决策日志，再进入正式策略；信息不足后继续在显式假设下工作，不停在问答阶段。

Product Truth / Claim / Value 至少区分：
- 真实事实 / Fact；
- 真实卖点 / Real Selling Point；
- 可感知利益 / Perceived Benefit；
- 情绪价值 / Emotional Value；
- Claim Boundary / 不可宣称项；
- 证据等级 A/B/C；
- 来源 / scope / publication status。

A = 检测报告 / 官方认证 / 可复现实测；B = 供应链规格 / 配方 / 成分机理 / 有边界事实支持；C = 主观体验 / 创意假设 / 待验证。C 不得成为硬宣称。

## 2. FULL 市场 / 区域 / 人群 / 文化深度
`03_platform_region_audience_culture_insight` 不能只有“目标人群几条 bullet + 多元文化一句话”。以下维度必须逐项有状态与依据：

`platform / market_region / subregion_geography / audience_segments / age / gender / income_spend / language / race_ethnicity / religion / holiday_calendar / payment / logistics / local_regulation / platform_behavior / search_demand / competition / price_band / intersectionality / stereotype_taboo`。

每个维度状态只能是：`EVIDENCED / ASSUMPTION / TO_VERIFY / MISSING_INPUT / NOT_RELEVANT`，并说明依据、假设或为什么不适用。不得静默省略。

### 交叉性
至少把相关的 `族裔 × 性别 × 年龄 × 收入 × 地域` 以及必要时语言、宗教、生活方式放进交叉性表，输出：维度组合、商业/表征含义、证据或假设、刻板印象防护、具体执行。

身份维度只用于**表征、语言、场景、可达性、禁忌、文化语境**等有证据的决策；不得把族裔/宗教自动推断为肤质、价格敏感、购买意愿或其他行为。

### 本地化运营表
FULL 项目显式覆盖：
- 语言与 native review / back-translation；
- 节日 / 宗教日历；
- 支付；
- 物流 / 履约承诺；
- 宗教 / 禁忌；
- 当地法规 / 平台规则。

未知就写 `TO_VERIFY / MISSING_INPUT`，同时说明对 Listing / Content / Visual / Offer / CTA 的影响，不能把未知维度删除。

## 3. 每个重大策略必须回答 WHY + 取舍
重要决策使用：
`WHAT → WHY → EVIDENCE → TRADEOFF → CONSUMER LOGIC → PLATFORM LOGIC → REGION/CULTURE LOGIC → BUSINESS LOGIC → EXECUTION → MEASUREMENT`。

表格优先。`premium / clean / suitable audience / optimize conversion` 等形容词不能替代依据、取舍和动作。

## 4. 框架关系，不机械套模板
RACE 是流程骨架：`Research → Action → Communication → Evaluation`。
STP + JTBD 定策略；AIDA / FABE 定内容组织；4P / Funnel 定转化与商业动作。FULL 输出明确每个框架在当前项目中“用来解决什么 / 为什么使用 / 哪些地方不适用”，而不是只出现框架名。

必须物化：
- RACE传播框架执行表；
- 平台内容矩阵的 RACE 阶段；
- 族裔文化适配 / 禁忌校验；
- 文化适配检查表。

## 5. 视觉与摄影执行深度
FULL 视觉策略至少显式处理：风格/情绪板方向、构图规则、角色化 HEX 色板与对比、灯光方向/CCT/光比/柔硬、镜头焦段/景别/机位/工作距离、场景、道具/元素、Subject Presence、平台尺寸、Shot List、CMF/材质、色彩管理与 finishing。

人物不是强制主体。主体继续使用 v0.6.46 `PERSON / ANIMAL / PLANT / PRODUCT_OR_OBJECT / ENVIRONMENT / MULTI_SUBJECT / NONE`。

### 人物出现时，Inclusive Photography = P0
只要画面出现人物、手、身体关系，至少处理：
- skin-tone exposure；
- deep-skin shadow protection；
- neutral reflector / bounce / diffusion；
- hair texture / styling；
- body representation；
- disability representation；
- age representation；
- AI bias review。

若没有人物，不强塞这些参数；动物/植物/物件使用相应真实材质、毛发/羽毛/叶片/花瓣、动作/福利/结构约束。

## 6. 平台执行必须到生产层
每个实际 Surface 行按相关性给：
`平台 / 人群 / 选题 / Hook / Script Structure / Visual Form / CTA / Metric / RACE / Culture & Taboo / Dimensions / Duration / Cover or First Frame / Subtitle / Music Rights / Traffic Mechanism / Landing Handoff / UTM or Attribution / WHY`。

平台算法、流量机制、法规或实时规则不能确认时标 `TO_VERIFY`，不能编造。

## 7. 预算 / 周期 / 资源约束必须做取舍
FULL 项目输出 Resource Tradeoff Plan：当前约束、P0/P1/P2、保什么、砍什么、为什么、依赖和恢复条件。

P0 = 不做会翻车；P1 = 明显影响效果；P2 = 增强项。不得用“全都要”代替取舍。

如果 Strategy / Content Matrix 已激活 Creator Video、Paid/Spark、Social、A+、Test 等，但最终没有对应对象或明确 `NOT_NEEDED` 决策，则是 **MATERIALIZATION GAP**。

Design Card 不能只剩 `question + composition + photography + cmf`。

按相关性必须保留：

大量资产复用完全相同的 Production Notes、Measurement Hypothesis、摄影合同或版式骨架，不能用“品牌一致性”解释。重复率异常时回 Agent 重新策展。

## 10. Prompt 语言与密度
Prompt 长短没有目标，**具体生产决策被消费**才是目标。

- CN Prompt = 中文生产执行权威；
- EN Prompt = 英文/provider执行语言；非中国目标下不得混入中文执行说明；
- 目标市场 exact visible copy 可按原语言保留；
- Visible Copy Block 与 Prompt 分离；
- Assembly/工程规则不污染模型 Prompt；
- 已选摄影/灯光/CMF/主体/场景/证据/几何参数不得在最终 Prompt 中被压成“premium / warm white / soft light”。

## 11. 全局语言矩阵
中国平台/中国大陆市场：中文为主。
非中国且平台主语言非英语：**English baseline + Platform Primary Language + 中文释义/用途**。
平台主语言英语：English + 中文释义/用途。
平台未指定：English baseline + 中文释义，平台主语言待指定。

Listing 的类目、标题、卖点、Description、Attributes、Variations、Package Contents、Usage、FAQ、Search Terms，以及 Visual/Video/Ads/Creator/Review/Research 外文运营内容都必须原文 + 同对象中文释义。`待补中文释义` 不是完成态。

## 13. 完成前自检
FULL 在声称完成前至少验证：
1. 是否编造；
2. 重大决策是否回答 WHY + 依据 + 取舍；
3. 市场/区域/人群/文化各维度是否显式处理；
4. 交叉性、宗教、禁忌、节日、本地化是否有证据/假设边界；

6. 平台执行/归因是否闭环；
