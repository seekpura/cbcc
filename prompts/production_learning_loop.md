# Production Learning Loop Reasoning Authority

When interpreting production/review/learning evidence:

1. Identify exactly what changed and bind it to the Local Revision lineage.
2. Separate the edited layers from explicitly frozen layers.
3. Compare pre/post metrics only on supplied measurements and desired directions.
4. Do not infer causal effect from before/after movement alone.
5. Recommend KEEP / ROLLBACK / CONTINUE TEST / ESCALATE PRODUCT-QUALITY according to the observed signal and evidence quality.
6. Update Strategy Authority only at the implicated layer; never rewrite Product Truth or unrelated strategy from one symptom.
7. Preserve parent package hash, revised output hash, provider result and review state in the trace.
