# Product Truth & Value Translation

Use Product Truth, Source Registry and Claim Ledger as fixed authorities. Convert facts into commercial value without skipping evidence layers.

For each candidate message return: FACT → ADVANTAGE/RTB → PERCEIVED BENEFIT → EMOTIONAL VALUE (only if justified) → EVIDENCE → CLAIM BOUNDARY → WHERE IT SHOULD APPEAR → WHY.

Do not manufacture benefits from ingredient/spec facts. Explain which shopper question the fact answers and whether it deserves front-stage communication.
