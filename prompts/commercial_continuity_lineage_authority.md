## v0.6.46 Commercial Continuity & Decision Lineage Authority — highest current precedence

### 商业级交付不是“模块都存在”，而是完整连续消费
CBCC 的完成链必须是：**Source → Analysis → Decision → Strategy → Curation → Asset → Human Design Card → Model Prompt / Production Assembly → Human HTML → Measurement / Revision**。

任何能力只存在文件、状态码、计数或摘要，但没有被下一层真实消费，都视为 **CONTINUITY GAP**，不得声称商业级完成。

### 1. Canonical 不得被安装包缩减
- Repo root `SKILL.md` 是成熟 Canonical 真源；正式插件的 Host Skill 与 `resources/SKILL.md` 必须使用完整 Canonical，并叠加当前版本权威，不能用 compact wrapper 替代完整商业能力。
- Builder / Guard 必须校验 Host == Canonical、Canonical 不得异常缩小，并包含 FULL 商业深度、七工具、Production Parameter Closure、摄影/灯光/CMF、Asset Universe、中文/语言合同、v1 工作台和本节。
- `defaultPrompt` / `agents/openai.yaml` 不承载平行业务规范。

### 2. 七工具输出必须传真实 payload，不得压成 status/count
相关时必须保留并可继续消费：
- Market：市场结构、需求/搜索、竞争、Price Bands、Price Valleys、Price×Configuration、Customer Voice、机会与风险；
- Audience / Region / Culture：目标区域、人群、语言、文化/族裔/交叉性、场景与主体执行含义、禁忌/刻板印象边界；
- Product Strategy / Pricing / Economics / Offer：SKU role、显式售价、成本、Contribution、Margin、Break-even CPA/CPC/ROAS、Offer/Bundle/Discount boundary、Pricing Decision + WHY；
- Listing/Search：关键词意图、字段任务、Objection、Final Copy、Claim/Fact trace；
- RACE / Journey / Content：当前阶段、目标、动作、Surface、Handoff、KPI；
- Ads：流量/点击/PDP/Offer/Economics 诊断、Creative diagnosis、Attribution、P0/P1/P2；
- Review / CS / Returns：主题、误解/期望差/真实缺陷、正向价值、最小修订责任层；
- Experiment / Measurement：假设、控制变量、结果、Keep/Kill/Iterate、回流对象。

缺真实输入时保持 `MISSING_INPUT / UNSPECIFIED`，不得为连续性而编造。

### 3. 单一 Commerce Decision Context + Per-Asset Decision Lineage
- 项目级 `Commerce Decision Context` 汇集当前项目真实商业决策及来源。
- 每个资产按 `consumer_question / purchase_barrier / decision_intent / Surface / RACE / business_hypothesis` 绑定最小相关决策集合。
- 价格/Offer 只进入真正相关的资产；Ads 诊断只进入 Paid/修复相关资产；Review 信号只进入相应误解/期望/使用/退货修复资产。
- 每个绑定保留 `source_artifact / source_path / domain`，让人和 Runtime 都可追溯。
- Curation / Art Direction 必须说明商业决策依据；不能只有视觉风格依据。

### 4. Subject Presence System：主体不等于人物
人物不是全局默认，也不是每张资产强制元素。每个资产按购买任务作者化 `Subject Presence System`：
- `PERSON`：人物；
- `ANIMAL`：动物 / 宠物；
- `PLANT`：植物；
- `PRODUCT_OR_OBJECT`：商品 / 物件；
- `ENVIRONMENT`：环境 / 空间本身承担主体；
- `MULTI_SUBJECT`：人物+动物、商品+植物等复合主体；
- `NONE`：明确无需人物/动物/植物主体，由商品、证据、环境或信息关系承担画面任务。

逐资产相关时至少作者化：`primary_subject / secondary_subjects / action / subject_product_relationship / subject_scene_relationship / subject_constraints`。Runtime 只能迁移已有显式 legacy `human_context / animal_context / plant_context`；不得因商品类目推断“应该有人”，也不得把宠物用品自动变成人物图、植物用品自动变成植物图。主体选择必须进入 Design Card 与 Model Prompt；不相关时允许 `NONE / N/A`。

### 5. Commercial Asset Universe：平台容量只限制 Activation Set
Asset Universe 不受 7/9 图、1 视频等平台槽位总数限制。平台容量只约束当前 `LIVE_CANDIDATE` 的 simultaneous activation set，绝不能 prune 总资产宇宙。

CBCC 必须允许但不强制配额的资产族包括：
- `HERO`；
- `BENEFIT`；
- `PROOF`；
- `SCENARIO`；
- `HOW_TO / ROUTINE`；
- `TRUST / WHAT_YOU_RECEIVE`；
- `PDP / LONGFORM / COMPARISON / FAQ`；
- `A_PLUS`；
- `AD`；
- `SOCIAL_SEEDING`；
- `CREATOR_UGC`；
- `VIDEO`；
- `BANNER / STORE`；
- 以及当前项目需要的其他动态资产族。

部署状态至少允许：`LIVE_CANDIDATE / TEST_POOL / ROTATION_POOL / PAID_MEDIA / PDP_CONTENT / APLUS_CONTENT / SOCIAL_CONTENT / ARCHIVE / OTHER`。Hero H01/H02/H03、同一卖点的不同机制、人物/动物/植物/无主体测试、不同场景/构图/证据机制、Paid、PDP/A+、种草、Creator/UGC、视频和 Banner 可并存，只要各自拥有独立商业/创意假设。不得因为 question/surface/family 相同就合并掉真实 A/B 变体。

### 6. 商业决策与视觉生产参数必须同时闭环
商业连续性升级不得削弱视觉/摄影深度。摄影/摄影式资产相关时必须保留 Agent 已选择的：
- focal length / lens family；
- working distance；camera height；yaw/pitch/roll / azimuth/elevation；
- framing / crop / safe zone；focus plane；aperture / DOF；相关时 shutter / ISO；
- key / fill / negative fill / rim / modifier placement；
- CCT / WB / exposure ratio / shadow / highlight；
- reflection control / polarization；Prelight；
- CMF / material response；color management；finishing / grade；
- 人物相关时 skin exposure / deep-skin highlight protection / bounce / diffusion / wardrobe-material interaction；动物/植物相关时改用适合该主体的毛发/羽毛/叶片/花瓣/表面高光、色彩与运动/静态表现，不套人物摄影默认。

真实摄影中需要现场测量的值可标 `PRELIGHT_DEPENDENT / TO_MEASURE_ON_SET`；这与“删除参数”不同。

### 7. Prompt 只消费 generation-relevant 商业决策
Model Prompt 必须同时继承：
- 当前资产商业任务、购买问题、信念变化、核心主张；
- 与该资产相关的市场/人群/文化/搜索/异议/RACE/Offer/Ads/Review 信号；
- 逐资产 Subject Presence System；
- 逐资产 Art Direction；
- 所有已选且会改变像素/帧的摄影、灯光、CMF、材质、空间、文字与输出参数。

经济公式、Runtime 状态、审计码、无关工具数据不得堆进模型 Prompt；它们进入 Design Card / Production Assembly / Inspector。

### 8. 商业 HTML 一等可见
在冻结的 `cbcc-commercial-v1` 内，当前项目真实存在时必须让运营人员可直接进入并读取：
- 市场 / 区域 / 人群 / 文化；
- Pricing / Economics / Offer；
- Search / Listing / Objection；
- RACE / Journey / Content；
- Ads / Measurement；
- Reviews / Customer Voice；
- Asset Universe / Activation / Test / Rotation / Paid / PDP / A+ / Social；
- Per-Asset Decision Lineage / Subject System / Art Direction / Photography / Prompt / Assembly / QA；
- Evidence / Source lineage。

这些对象是商业工作面，不是 Machine Archive。Machine JSON 保留用于审计，但不能替代人类主交付。
