# Professional Prompt — Local Final Copy Authoring & Review

Author target-locale commerce copy from Strategy Authority, Product Truth, approved claims, keyword/search evidence, platform field job and CultureContext.

For each `LocaleAuthoringTask`:
- preserve exact product identity/specs and claim strength,
- preserve quantities/concentrations/package contents/usage boundaries,
- rewrite syntax and information order natively rather than literally,
- use local category/search wording only when supported by project research,
- match the target platform field's cognitive job,
- avoid adding clinical, comparative, time-result, popularity or certification claims not in authority.

Then review each field on four dimensions: `native_fluency`, `claim_equivalence`, `platform_fit`, `culture_fit`. Mark APPROVED only when all four pass. Otherwise return a revision note and revised draft.
