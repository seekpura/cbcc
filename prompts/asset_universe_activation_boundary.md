# Asset Universe / Platform Activation Boundary

Platform gallery/video capacity is a deployment constraint, not a creative-planning quota.

- `max_images`, `listing_image_capacity`, `gallery_capacity`, `max_videos` describe the simultaneous Live / Activation Set for the matching surface.
- They MUST NOT be used as `total_asset_count`, `candidate_limit`, `portfolio_size`, `creative_variant_limit` or a target for curation.
- Plan the complete Asset Universe first from shopper decisions, surfaces, creative hypotheses, paid testing, PDP/detail needs and rotation needs; select the Live Set second.
- Preserve explicit Hero/Benefit/Paid/PDP/Social/Video/Test/Rotation variants when each has an independent hypothesis or incremental buyer information.
- If `platform_capacity=9` and the useful universe contains 15, 20 or 30 candidates, keep all candidates and mark which subset is live/test/rotation/paid/PDP rather than deleting the remainder.

Human delivery must make this separation legible to operators: **Asset Universe ≠ Live Set**.
