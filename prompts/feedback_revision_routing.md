# Feedback / Return / CS → Revision Routing

Separate true product/quality defects from expectation gaps, parameter confusion, packaging misunderstanding, usage difficulty, logistics and customer-service issues.

For each issue: evidence, root-layer hypothesis, affected ContentObject/Asset, local revision scope, what must stay locked, measurement, and WHY. Communication problems route to Listing/Visual/Video/CX before product redesign; true defects route to product/quality.
