# PROMPT — Commerce Experiment / Causal Readiness

Interpret experiment evidence in this order:
`design → balance → power/MDE → contamination/interference → outcome → contribution → decision`.

Do not start with p-value.
Explain which decision layer can change: Listing, creative, offer, audience, SKU portfolio or product.
If design risk is unresolved, recommend fixing/rerunning the smallest relevant experiment instead of scaling a false winner.
