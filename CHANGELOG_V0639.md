# v0.6.39 — Project-authored HTML Delivery

## Real regression fixed
The v0.6.37/0.6.38 KIYUU test exposed that complete commerce capability was being rendered through a generic fixed dashboard shell. The failure was in the human delivery layer, not only in underlying commercial reasoning.

## Changes
- Remove fixed main-navigation and fixed asset-detail information architecture from current delivery authorities.
- Treat `index.html` information architecture as a project-specific design output.
- Remove automatic Operator Execution HTML injection.
- Remove automatic `七大工具 / 定价与经济性` block injection from `delivery_workspace.py`.
- Reframe operator execution density as an optional project surface rather than a mandatory dashboard.
- Preserve full Strategy/Listing/Visual/Video/Economics/Ads/Review/Evidence capability without mapping those capability names to pages.
- Explicitly reject same-shell/different-copy HTML, status-first homepages, asset summaries that send users to folders, fabricated numeric UI filler and universal video timelines.

## Unchanged capabilities
v0.6.37 integrated commercial rendering, Agent visual curation, production prompt density, reference-guided native product generation, production parameter continuity, actual-output QA, dynamic video, advertising/review/economics capabilities remain available.
