# Category Commerce Depth

Cross-category strategy must reuse the **decision method**, not the same objection list, proof order, offer pattern, message sequence, or content cadence.

## Commerce profile

For each category family, compile five linked authorities:

1. **Objection priority** — which uncertainties are expensive enough to resolve before persuasion advances.
2. **Proof hierarchy** — which evidence types should appear earlier because they answer more fundamental purchase risk.
3. **Offer architecture** — category-appropriate offer hypotheses that still require Product Truth, unit economics and platform validation.
4. **Message architecture** — the category-specific order of beliefs, while preserving one Primary Conversion Proposition.
5. **Content cadence** — which decision modules should rotate and what evidence changes should trigger refresh. Cadence is not an invented posts-per-week quota.

## Category examples

- Beauty: routine fit → approved proof → usage/expectation boundary before discount pressure.
- Apparel: size/garment measurements → body fit → fabric/care before styling inspiration or multi-buy.
- Food/beverage: label/net content → ingredients/nutrition/allergen/certification → real preparation/sensory evidence → pack/storage.
- Electronics: compatibility → task-relevant performance with test conditions → setup → warranty/package.
- High-ticket durables: site fit → performance/build → delivery/installation → service → total ownership cost.

## Truth boundary

A category profile is a prioritization model, not a fact generator. It must never invent sensory descriptions, certifications, compatibility, warranty, delivery scope, return policy, performance, installation service or health claims.
