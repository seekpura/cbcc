# Portfolio Switch / Holdout / Marginal Contribution

Separate structural SKU overlap, observed cross-shopping, directional switching, cohort behavior and causal incrementality. A switch rate requires an explicit eligible-from denominator. Holdout arithmetic should report incremental orders and **net incremental contribution** after intervention cost, while statistical significance, power, assignment integrity, interference and contamination remain experiment-review questions.

Portfolio decisions should prefer incremental contribution over attributed revenue.
