# Strategy Revision Integration — Ads / Feedback / Market Evidence -> Local Change

## Principle

Measurement is useful only when it routes back to the smallest strategy layer that could plausibly cause the observed symptom. A low CTR is not permission to rewrite Product Truth, SKU strategy, PDP proof, price and visual system simultaneously. A return/CS issue is not permission to redesign the whole brand.

## Ads routing

Use causal order:

1. Eligibility / reach
2. Click package
3. PDP / traffic quality
4. Economics
5. Incrementality

Typical routes:

- `LOW_IMPRESSIONS / ELIGIBILITY_TRAFFIC` -> eligibility, indexing, query/placement coverage, inventory, bid/budget. Freeze unrelated Product Truth / positioning / visual style.
- `LOW_CTR / CLICK_PACKAGE` -> P0 message, title/hero/thumbnail/first frame. Change one first-impression variable at a time. Freeze unrelated PDP modules and SKU architecture.
- `LOW_CVR / PDP_CONVERSION` -> traffic intent, fit, proof hierarchy, objection handling, price/offer/trust. Do not immediately blame creative.
- `CPC / media efficiency` -> bid, auction, query/placement mix. Do not rewrite product claims from media-cost symptoms.
- `ROAS/economic floor` -> offer economics, margin and media spend; do not hide a bad cost structure with more creative.

## Feedback routing

Classified feedback should distinguish product/quality defects from communication/expectation problems. Route only the implicated layer and freeze unrelated layers. Usage confusion should route to usage content/video/CX; package confusion to listing/package/CX; compatibility to attributes/listing/CX; real product defects to product/quality.

## Market evidence fit routing

Search/review/competitor observations are not revision instructions by themselves. They first create Product-Truth Fit tasks. Only confirmed fit creates a new decision job / asset route.

## Integration contract

A Runtime capability counts as integrated only if its output changes or constrains one of:

- Strategy Authority;
- Dynamic Asset Architecture;
- per-asset 00–11 production package;
- Final Copy author/review/release;
- Provider Job / production contract;
- Measurement / local revision routing.

A calculator file, prompt file, ontology entity or passing test does not by itself count as integration.
