# Offer Response Evidence Authority

## Purpose
Use real contribution economics and observed offer behavior to validate category-shaped Offer hypotheses.

## Evidence types
- Promo/price response: descriptive price, discount, conversion/order and contribution observations.
- Bundle affinity: explicit eligible denominator, paired orders, attach rate and any separately supplied incremental contribution.
- Repeat/replacement cycle: observed cohort timing and repeat rate.
- Holdout/incrementality: net incremental contribution is stronger than attributed revenue.

## Rules
- Observed price/quantity response is not causal elasticity unless the design supports that claim.
- Bundle attach rate is not incremental bundle lift.
- Repeat timing does not create recommended usage frequency.
- Service, warranty, delivery, financing and installation offers require actual capability/policy evidence.
- A category-shaped offer becomes an evidence-supported TEST CANDIDATE, not an automatically locked offer.
