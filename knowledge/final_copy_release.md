# Local-language Final Copy Release

## Principle
A localized string is not Final Copy merely because it has been translated or generated.

## Workflow
`Strategy Authority → Locale × Field Authoring Task → Native Draft → Deterministic Hard Audit → Native Fluency Review → Claim Equivalence Review → Platform Fit Review → Culture Fit Review → APPROVED_FINAL`.

## Deterministic hard audit
- numerical equivalence,
- required/disallowed field terms where encoded,
- title length/bytes where encoded,
- required field presence,
- Product Truth and claim/source lineage contracts.

## Professional review
Native fluency, claim-strength equivalence, local commerce naturalness, cultural fit and platform-native information ordering require explicit reviewer/model authority; deterministic runtime must not pretend to infer them.

## Release rule
No draft becomes `APPROVED_FINAL` unless the copy exists, hard checks pass, and all required review dimensions are explicitly approved.
