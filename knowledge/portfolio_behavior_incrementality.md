# Portfolio Behavior / Cohort / Incrementality

## Purpose
Structural SKU overlap is a hypothesis. Portfolio strategy becomes stronger when actual behavior validates or rejects it.

## Evidence ladder
1. **Structural overlap** — same buyer job / segment / configuration / channel / price / role.
2. **Observed behavior** — cross-shopping, shared visitors, switching, exclusive orders.
3. **Cohort behavior** — acquisition, repeat, contribution and lifecycle performance under a defined cohort/window.
4. **Counterfactual / incrementality** — treatment-control results with declared assignment/design.
5. **Statistical/causal review** — significance, assignment integrity, interference, novelty and duration.

## MUST
- Never turn observed overlap into a cannibalization percentage without a counterfactual.
- Never call descriptive cohort differences causal.
- Arithmetic lift from treatment/control aggregates is not enough to declare causal impact.
- Portfolio roles should be revised when behavioral evidence contradicts structural assumptions.
- Judge SKU value by incremental demand/contribution/lifecycle role, not only standalone revenue.

## Commercial use
Use behavioral evidence to decide whether to merge, differentiate, reposition, bundle, trade up, retire, channel-separate or retain adjacent offers.
