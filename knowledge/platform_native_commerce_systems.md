# Platform-native Commerce Authoring Systems

One Strategy Authority does not mean one universal piece of copy.

## TikTok Shop
Discovery/content traffic can enter with low prior intent. Native sequence: exact identity → relevance/demonstration → proof/risk reduction → product click/shop action. Copy should be spoken-natural, subtitle-safe and beat-based.

## Shopee
Comparison friction is central. Native sequence: search relevance → decisive spec/value comparison → trust/proof → package/usage/FAQ → order/chat. Copy should be compact and scan-friendly.

## Amazon
Search relevance and compliant product identity define the comparison set. Native sequence: search identity → core benefit → proof/spec → objection/usage → deep proof/A+ when available. Keyword relevance must remain readable and field-compliant.

## DTC / Shopify
The brand controls more of the landing and lifecycle. Native sequence: promise/identity → proof → fit/use case → objection → usage/package → offer/CTA → retention. More narrative depth is allowed, but each module must move one belief state.

## Reuse rule
Reuse Product Truth, Positioning, Message Hierarchy and evidence. Re-author surface order, hook, density, CTA and production form.
