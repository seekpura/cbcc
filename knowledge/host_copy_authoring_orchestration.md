# Host / Model Final Copy Orchestration

## Role split
The runtime owns deterministic state, facts, numeric invariants, platform field constraints, version lineage and release status.
The host/model authors native copy from Strategy Authority and task artifacts.
Professional reviewers own native fluency, claim equivalence, platform fit and culture fit approval.

## Version law
Every authored or revised response creates a new locale × field version. It NEVER inherits approval from its parent.
A response must identify locale, field and copy; version/parent/task metadata should be retained.
Review approval is valid only for the exact current version.

## Loop
`AUTHOR TASK → HOST RESPONSE → NEW VERSION → HARD CHECK → REVIEW TASK → REVIEW → (REVISION TASK → NEW VERSION → RE-REVIEW)* → APPROVED_FINAL`

## WHY
Generation quality and release authority are different concerns. Separating them allows strong language models to write naturally without weakening claim, evidence or approval control.
