# Production → Review → Local Revision → Learning

- Production outputs never rewrite the frozen `00–11` asset package in place.
- Review revision requests must carry an explicit asset, requested change and `allowed_fields`; unspecified scope stays on hold.
- A Local Revision Provider Job inherits the parent package hash and frozen production contracts. The revised output receives its own output hash and lineage.
- Provider completion does not equal review acceptance. The revised output is independently reviewable.
- Post-change before/after movement is descriptive unless a valid causal design supports attribution.
- Learning must revise the smallest evidence-implicated strategy layer and keep unrelated Product Truth, Positioning, Offer or Visual layers frozen.
- Strategy Authority records a Learning Ledger so future decisions know what changed, why, what happened and whether causal credit is allowed.
