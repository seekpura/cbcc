# Feedback Intelligence
Classify PRODUCT_DEFECT, EXPECTATION_GAP, MISUNDERSTANDING, PARAMETER_CONFUSION, PACKAGE_CONFUSION, USAGE_DIFFICULTY, SIZE, COMPATIBILITY, TEXTURE, LOGISTICS, CUSTOMER_SERVICE, OTHER. Preserve raw evidence and sample limitations. Map Feedback → Root Cause → Responsible Module → Listing Field → Asset ID → Revision Request.
