# Visual Strategy

Read `references/CREATIVE_SYSTEM_SPEC.md`, `references/PHOTOGRAPHY_CMF_SPEC.md`, and `references/POSITIVE_FIRST_POLICY.md`.

## Inputs
Product Truth, Listing hierarchy, Decision System outputs, brand, audience/culture, platform/surface plan, real assets and approved claims.

## Process
1. Curation: classify truth/visual/category/culture/anti-pattern references and record what each reference contributes.
2. Explore 2–4 materially different creative territories with product/consumer/platform/culture/differentiation rationale.
3. Select the primary territory and, where useful, a Foundation/Creative Anchor Asset.
4. Build CMF: product-truth CMF separately from campaign palette/materials/finishes.
5. Build information design: hierarchy, reading path, mobile density, whitespace and typography-safe zones.
6. Build a production-grade photography/CG contract: focal length, camera geometry, composition, product occupancy, focus/DOF, key/fill/negative fill/rim, modifier size/distance, CCT, contrast, exposure/highlight policy, reflections, shadows, color management and material handling.
7. Build inclusive casting/skin-tone/hair/wardrobe/makeup/gesture strategy when humans help the approved job.
8. Select semantic elements positively from the asset strategy; evaluate claim/culture/platform implications with the Visual Semantics Gate.

## Outputs
`curation_map.json`, `visual_territories.json`, `visual_strategy.json`, `foundation_anchor.json` when useful,
`cmf_system.json`, `information_design.json`, `photography_framework.json`, `casting_strategy.json`, `visual_semantics_decisions.json`.
