# Locale, Typography & Transcreation Contract

Human delivery language and asset language are separate authorities.

Each asset language contract resolves:
- primary/support/visible-copy locales;
- script family;
- LTR/RTL direction;
- line-breaking strategy;
- information-density considerations;
- prompt instruction language;
- native editorial review requirement.

Technical typography profiles support production repeatability. Marketing transcreation remains meaning-preserving and target-native rather than literal by default; native editorial quality requires a qualified reviewer or verified target-language source.
