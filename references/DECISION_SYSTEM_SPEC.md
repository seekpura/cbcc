# Decision System Specification

The Decision System determines what the commerce experience must make the customer notice, believe, understand and do.
Frameworks are selected because they change a decision, not because they exist in the library.

## Core stack
- RACE: Research / Action / Communication / Evaluation.
- STP + JTBD: segment, target, position, then functional/emotional/social job, trigger, desired outcome, anxiety, barrier, alternative and switching friction.
- 4P + conversion funnel: product, price, place, promotion mapped to discovery/search/PDP/cart/checkout/retention.
- AIDA / FABE: optional message structuring for a specific asset or copy block.

## Behavioral / belief models
- Fogg Behavior Model: motivation × ability × prompt; use to diagnose action friction.
- Means–End Chain: attribute → functional consequence → psychosocial consequence → personal value.
- Signaling Theory: identify what concrete evidence increases trust and what only looks decorative.
- FIRST Hero Gate: first-screen decision gate—identify product, primary value, fit and next action with minimal cognitive friction.
- Cognitive Budget: allocate limited mobile attention; each asset must justify information cost.
- Commerce Response Ladder: notice → identify → understand → believe → fit → desire → act → confirm.
- Belief Sequence: sequence evidence so later claims depend on beliefs already established.

## Purchase-question priority
Rank consumer questions by conversion impact, uncertainty, evidence availability and surface suitability.
This ranking drives asset count and order; there is no predetermined gallery size.

## Measurement hypothesis
Each material strategy choice should have an observable hypothesis and metric where measurement is possible.
