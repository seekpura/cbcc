## 0.1 Master construction + full Art Direction non-regression lock
This release is additive over v0.6.51. **修复一个维度不得压缩另一个维度。** 中文化不得压缩策略与 Prompt；合规不得压缩创意；Prompt 语言纯度不得删除画面世界；UI 不得隐藏业务对象；媒体自包含不得丢 Source Truth。

**Prompt ≠ 摄影参数集合。** 摄影/灯光只是逐资产 Art Direction 的一个层。每个生产资产必须先由 Agent 闭合当前相关的：商业决策与购买障碍、人物/主体、动作与 decisive moment、元素、场景、环境、道具、商品角色与出现节奏、视觉载体与视觉钩子、构图语法与空间关系、尺度/深度/焦点路径/负空间、证据层级、文案/字体/排版/目标市场语言、文化与包容性、CMF/材质/颜色、摄影/光学/灯光、平台/站点/Surface/设备/输出、Video/Creator/LIVE 的时序/运动/音频、与相邻资产的差异化。QA 与最小责任层修复属于 Review / Revision，不得因为“完整 Art Direction”而塞进 Model Prompt。

只含摄影参数、只含风格词、只含产品+背景或只有几句商业任务的 Prompt 都不是商业级生产对象。Model Prompt CN/EN 必须无损消费已经选定、会改变像素/动作/时间轴/排版/材质响应的具体 Art Direction 决策；不能把这些全部移到 Production Notes 造成模型实际 Prompt 变薄。

## 0.2 Full business-object density non-regression lock
**Prompt 只是业务链中的一个对象，不是整个 CBCC。** FULL 项目必须同时保留各业务域自己的真实决策深度，不能把所有内容汇总成 Prompt，也不能为了修中文、UI、合规、媒体、Prompt 或某个资产而把其他域压成摘要。

每个重大业务对象至少回答：`WHAT → WHY → EVIDENCE → TRADEOFF → EXECUTION → MEASUREMENT`。相关域必须分别物化：
- Product Truth：事实完整度、来源冲突、真实卖点/可感知利益/情绪价值/不可宣称项、A/B/C、claim boundary；
- Research / Market：需求、搜索、竞争、价格带、评论/差评、机会、风险、证据/置信度及对 downstream 的影响；
- Audience / Culture / Intersectionality：平台×区域×人群×族裔文化 WHY，族裔×性别×年龄×收入×地域，语言/宗教/节日/支付物流/禁忌/刻板印象及具体执行后果；
- Strategy / Frameworks：定位、价值主张、信息层级、信念序列、STP/JTBD、AIDA/FABE、4P/Funnel、RACE、资源取舍、指标，不得只列框架名；
- Pricing / Economics / Offer：价格带、Price×Configuration、Contribution、Margin、Break-even CPA/CPC/ROAS、Offer Boundary、显式输入与 MISSING_INPUT；
- Listing / Search：关键词、标题、卖点、描述、属性、package/usage/warning、FAQ、Claim Mapping、平台字段、publishable target-market copy + 中文释义；
- Content Matrix：平台、人群、选题、Hook、脚本结构、视觉形式、证据、CTA、指标、RACE、文化校验、尺寸/时长/封面/字幕/音乐版权/流量/landing/UTM/归因/WHY；
- Visual Master：风格、moodboard、构图系统、HEX/对比、摄影/灯光、CMF/材质、人物/场景、Shot List、平台适配与反同质化；
- Asset Universe / Art Direction：每资产消费者问题、购买障碍、目标信念、增量信息、Visual Carrier、Product Presence、decisive moment、人物/动作/场景/道具/空间/证据/文案/CMF/摄影、Business Hypothesis、Metric、rhythm delta；
- Model Prompt / Production：CN / EN / Visible Copy / Production Notes 四对象及完整 Art Direction 无损编译；
- Video / Creator / LIVE：duration、beat、shot sequence、subject/camera motion、subtitle、VO、audio/music rights、CTA hold、平台原生节奏、LIVE objection/demo/offer loop；
- Advertising Optimization：受众状态、创意机制、offer、landing、经济模型、归因、测试、失败诊断与学习回流；
- Review Analysis：评论结构、问题分类、购买障碍、退货/差评、责任层、最小修复、对 Product/Listing/Creative/FAQ 的学习闭环；
- RACE / Localization / Compliance / Measurement：真实执行表、语言回译/节日/支付物流/宗教禁忌/法规、P0/P1/P2、A/B、归因、下一步输入；
- Evidence / Operations / Human Workspace：来源权威/时效/解释/决策日志、执行对象/依赖/完成标准、中文 canonical routed workspace 与自包含媒体。

以下都视为回归：策略只剩框架名或三五条结论；Listing 只剩标题 + 三条卖点；Content Matrix 只剩“教育/种草/转化”；Visual Master 被 Prompt 取代；Asset Design Card 被 carrier/camera/light 几个字段取代；Ads 只剩广告文案；Reviews 只剩情绪/关键词；Economics 因任务偏视觉而被省略；RACE/文化/合规/Measurement 只有标题没有执行内容；Human Workspace 用几张状态卡替代完整业务对象。

`resources/references/BUSINESS_OBJECT_DENSITY_MASTER_CONTRACT.md` 是该规则的完整施工权威。任何模块“有标题、有字段、有一两句话”都不能判密度 PASS。

## 0.4 Open-world Asset Opportunity Universe — highest asset-breadth precedence
FULL 项目先构建完整 **Asset Opportunity Universe**，再形成 Production Portfolio 与平台受限的 Activation Set(s)。**不得把“最少够用 / fewest assets / smallest sufficient”作为 Asset Universe 优化目标。** 平台 7/9/10 图、视频槽位或 Gallery capacity 只能限制同时上线集合，不能作为总候选数、生成停止条件、top-N 截断或资产家族裁剪依据。

Agent 必须在裁剪前按相关性检查 0..N 机会：Gallery/Hero/Search/PDP、Benefit/Proof/Ingredient/Material、Scenario/Lifestyle/Context/Human-use、How-to/Routine/Comparison/Objection、A+/Rich Content/PDP longform、Paid Ads、Social/Seeding、Creator/UGC/Affiliate、Video/PDP Video/Short Video/LIVE、Store/Banner/Landing/Campaign/Seasonal、CRM/Lifecycle/Post-purchase、Test/Rotation/A-B/multivariate。相关家族不生成时，必须给 `NOT_NEEDED / TO_VERIFY / MISSING_INPUT + WHY`，不得静默消失。

同一消费者问题、同一 Surface 也允许多个资产，只要存在不同的可测试商业/创意变量：Hook、证据载体、人群/文化框架、Offer/CTA、Product Presence、人物/动作/场景、Visual Carrier、构图机制、文案层级、动态 beat/运动、Creator performance 等。A/B 不是“装饰性重复”；有明确 hypothesis / tested variable / metric / deployment pool 就必须保留。

FULL Human Workspace 必须区分 **总候选 Universe** 与 **当前 Activation Set**，并保留 Test/Rotation/Paid/A+/PDP/Social/Creator/Video 等生产就绪对象的 Design Card + Model Prompt CN/EN + Visible Copy + Production Notes。不要因为当前 Gallery 只能上 9 张，就把全部资产做成 9～10 个。

完整规则见 `resources/references/ASSET_UNIVERSE_OPEN_WORLD_CONTRACT.md` 与 `resources/prompts/dynamic_asset_curation.md`。

## 0.5 Model Prompt Semantic Membrane — highest model-facing prompt precedence
**Model Prompt CN/EN 不是完整生产档案，只是发给图像/视频生成模型的执行指令。只有模型真正能看到、并会改变像素/帧/音频的内容才能进入。**

严格分离三层：
1. **Model Prompt**：画布、主体、商品角色、动作、场景、道具、构图、尺度、景深、证据呈现、文案（仅 MODEL_RENDER/HYBRID）、人物、CMF/材质、摄影/灯光、颜色、运动、最终质感与直接视觉排除项；
2. **Production / Assembly Notes**：Excel/文件真源、来源优先级、Provider 绑定、文件路径、Product Fidelity 机器枚举、可编辑/冻结层、后期装配与责任层；
3. **Review / QA / Revision**：生成后验收、拼写/几何/安全区/缩略图检查、合规复核、缺陷定位和最小修复顺序。

以下内容不得进入 Model Prompt：`Excel 为最高权威`、`source of truth`、xlsx/本地路径、内部 SKU/Asset ID（除非它本身是消费者可见文案或用于指代已真实绑定参考图）、`QA:`/验收清单、`最小修复`/repair order、Provider route、machine contract、audit status、editable/frozen layer 工作流。

Product Truth/Excel 仍然是上游最高事实权威，但必须先被 Agent **解析成模型可执行的具体事实**。例如不要写“数字只能来自 Excel”，而是在 MODEL_RENDER 时直接给出允许出现的精确数字并要求“不生成其他数字”；POST_COMPOSITE 时则完全不要把数字塞给图像模型。

Prompt 只有在 Provider Job 确实绑定参考图时，才可以写“使用已附带/attached product reference images”。模型看不到的 `K01 全视角包装图`、文件名、表名、路径不能假装成模型可理解的上下文。若参考图没有真正绑定，先绑定或把必要视觉事实显式编译出来。

QA 中真正会改变生成结果的要求，可以转换为正向像素约束：例如“手指数量正确、抓握自然”“标题保持在移动端安全区”“不生成额外营销文字”。但 `QA:` 标签、通过/失败判断和“文字层→泵头反射→整图重生成”之类修复链永远留在 Review / Revision。

完整规则见 `resources/references/MODEL_PROMPT_SEMANTIC_MEMBRANE_CONTRACT.md`。

## 0.10 One-to-One Long-Requirement Runtime Enforcement
For FULL projects the verbatim user requirements are real Runtime/Human/package contracts:
