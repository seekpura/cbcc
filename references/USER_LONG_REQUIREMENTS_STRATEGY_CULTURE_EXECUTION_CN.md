# 用户长要求原文锁｜策略、文化适配、执行与输出结构

## 权威性质

本文件保存用户在项目开发中明确给出的长要求原文。**不得摘要替代、不得只保留概念名、不得因为后续 Runtime/Prompt/UI 修复而弱化。**

发布时必须同时读取：
- 本原文锁；
- `CONVERSATION_REQUIREMENT_AUDIT.md` 中的归一化 requirement IDs；
- `SOURCE_REQUIREMENT_NON_REGRESSION_LOCK.md` 点名的其他施工权威。

归一化账本用于机器追踪，本文件用于防止“摘要后丢具体执行锁”。若两者表达粒度不同，以本文件保留的更具体执行要求为准，除非用户后续明确替换。

---

1. 先做产品事实审计：区分“真实卖点/可感知利益/情绪价值/不可宣称项”，按证据强度分级。证据等级：A=检测报告/官方认证/可复现实测；B=供应链或成分机理支持；C=主观体验/待验证。C级不得作硬宣称。
2. 所有策略必须回答：为什么这个平台、这个区域、这个人群、这个族裔文化背景下要这样做。
3. 合规与宣称证据为P0：功效、成分、认证、价格、销量、医疗/美妆/食品/金融等强监管品类单列检查，不可编造。
4. 做交叉性分析：族裔×性别×年龄×收入×地域，避免单族裔标签化和刻板印象。
5. 视觉包容性摄影为P0：深肤色曝光、发质造型、体型、残障、年龄呈现；避免AI生成偏见。
6. 平台执行考虑：尺寸、时长、封面、字幕、音乐版权、流量机制、CTA、落地页、UTM与归因；不确定标“待查证”。
7. 区域本地化考虑：语言回译、节日日历、支付物流、宗教禁忌、当地法规；不确定标“待查证”。
8. 预算/周期不足时明确砍什么、保什么；P0=不做会翻车，P1=影响效果，P2=加分项；不得用“全都要”替代取舍。
9. 策略每条给“依据+取舍”，表格优先，禁止空泛形容词；不要只给概念，要给决策理由和可执行清单。
10. 输出前自检：是否编造？是否回答“为什么”？是否做族裔文化校验？是否过合规？是否给指标？假设是否标注？

【三、文化适配与传播流程】
1. 族裔文化适配（race/ethnicity）：分析族裔身份、语言、宗教、节日、禁忌、肤色/发型/体型/家庭结构呈现、包容性表征、刻板印象规避；单列“族裔文化适配检查表”，并在平台内容矩阵中逐条校验脚本、模特、服化道、配色和CTA。
2. RACE传播框架（Research-Action-Communication-Evaluation）：作为传播流程骨架。
- Research：市场/平台/人群/族裔文化/竞品/产品事实研究；
- Action：策略与执行计划（定位、信息层级、内容矩阵、拍摄执行、预算节奏）；
- Communication：分平台传播、达人/UGC/广告/私域、语言本地化；
- Evaluation：各阶段指标、归因、A/B测试、复盘迭代。
3. 框架关系：RACE做流程骨架；STP+JTBD定策略；AIDA/FABE定内容结构；4P/内容漏斗定转化；不得只套模板不回答“为什么”。
4. 输出“RACE传播框架执行表”和“族裔文化适配检查表”；分平台内容矩阵增加“RACE阶段”和“族裔文化适配/禁忌校验”两列；文化判断标注依据或假设，禁止标签化和刻板印象。

【四、执行锁】
1. 顺序：信息审计→待确认清单→明确假设→再输出；信息不足最多列10问，随后在假设下继续，不得停。
2. 视觉执行给到：风格关键词、情绪板方向、构图规则、主/辅/背景/文字色HEX及对比度、灯光方向/色温/光比/柔硬、镜头焦段、景别、机位、场景、道具、模特与服化道、平台尺寸；深肤色须给曝光补偿与反光板/柔光方案。
3. 单独写“假设与决策日志”：哪些是事实、哪些是假设、为什么这样取舍。
4. 单节控制篇幅，表格优先；平台规则、算法、法规不确定标“待查证”，禁止编造。

【五、输出结构】
1. 信息完整度、待确认清单、假设与决策日志
2. 产品真实事实审计与卖点分级表（真实卖点/可感知利益/情绪价值/不可宣称项/证据等级）
3. 平台×区域×人群×族裔文化洞察（含交叉性、文化适配点、禁忌与刻板印象规避）
4. 营销框架与核心策略（定位、价值主张、信息层级、传播节奏、4P/内容漏斗）
5. 视觉总策略与拍摄执行清单（风格、构图、配色HEX、灯光摄影框架、焦段、景别、机位、场景、道具、模特服化道、平台尺寸、镜头表）
6. 分平台内容矩阵表：平台/人群/选题/钩子/脚本结构/视觉形式/CTA/指标/RACE阶段/族裔文化适配与禁忌校验
7. RACE传播框架执行表：阶段/目标/关键动作/输出物/平台/文化校验/指标
8. 族裔文化适配检查表：文化适配点/包容性表征/刻板印象与禁忌/校验结果/修改动作
9. 合规、文化敏感与风险清单；评估指标与A/B测试建议；P0/P1/P2执行优先级与下一步需补充信息

## 不可摘要掉的执行锚点

以下锚点必须在当前 FULL 交付/机器审计中可追踪，不能只在原则文档里出现：
- `信息审计 → 待确认清单 → 明确假设 → 继续输出`；最多 10 问，不得因信息不足停工；
- `真实卖点 / 可感知利益 / 情绪价值 / 不可宣称项` 四分法；
- A/B/C 证据强度与 C 级不得硬宣称；
- 平台 / 区域 / 人群 / 族裔文化 WHY；
- 族裔 × 性别 × 年龄 × 收入 × 地域；
- 深肤色曝光、反光板/柔光、发质、体型、残障、年龄和 AI bias；
- 尺寸、时长、封面、字幕、音乐版权、流量机制、CTA、landing、UTM、归因；
- 回译、节日日历、支付物流、宗教禁忌、当地法规；
- P0/P1/P2 取舍；预算/周期不足时明确砍什么、保什么；
- 每条策略“依据 + 取舍 + 执行 + 指标”；
- RACE 执行表与族裔文化适配检查表；
- Content Matrix 必须含 `RACE阶段` 与 `族裔文化适配/禁忌校验`；
- 假设与决策日志独立可见；
- 视觉总策略具备 HEX/对比度、灯光方向/CCT/光比/柔硬、镜头焦段/景别/机位、场景/道具/模特服化道/平台尺寸/Shot List；
- 不确定平台规则/算法/法规明确 `待查证`，禁止编造；
- 九项输出结构属于完整度/对象合同，不要求成为固定九页或永久导航。
