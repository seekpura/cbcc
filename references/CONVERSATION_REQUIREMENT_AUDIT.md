# Conversation Requirement Audit — v0.3.0

This file is the continuity handoff for requirements accumulated across the project. It prevents a later revision from treating the latest turn as the whole specification.

## Preserved strategy requirements
- Verified product truth and evidence-first claims; missing data remains explicit.
- Market / platform / region / audience research with current-rule freshness.
- RACE, STP + JTBD, optional AIDA/FABE, 4P/conversion funnel.
- Race/ethnicity, intersectionality and cross-cultural localization without stereotyping.
- Decision System: Fogg, Means-End, Signaling, FIRST Hero Gate, Cognitive Budget, Commerce Response Ladder, Belief Sequence.
- Listing as search→click→identify→understand→proof→fit→objection→trust→action, including keywords/title/bullets/description/attributes/usage/package/FAQ/claim mapping.
- Product/SKU roles, pricing/unit economics, advertising economics.
- Reviews/CS/returns/search/creator feedback → root cause → listing/surface/asset revision.

## Preserved creative requirements
- Creative System: truth → research → curation → creative territories → Foundation/Creative Anchor → CMF → photography/CG → information design → prompt/production → QA.
- Product-specific visual direction; anti-template check.
- Dynamic asset count; no default 9-image sequence.
- Multi-surface support: Listing/PDP/Gallery/Longform/A+/Shop/Shoppable Photos/Ads/Video/Creator/UGC/Social/Live/FAQ/Email.
- Asset metadata includes curation source, journey stage, entry/exit state, purchase barrier, surface, reason-to-exist, information gain, handoff, platform/market/locale.
- Product-fidelity modes including LOCKED_PIXEL and real-product composite workflow.
- Prompt/internal-state isolation and deterministic layout contracts.
- Local revision scope: named change only; other approved fields stay stable.

## Photography / CMF requirements
- Lens/focal length, camera height/distance/yaw/pitch/roll, shot size/crop/perspective.
- Product occupancy, safe margins, negative space, typography-safe area.
- Focus plane, aperture/DOF and macro working distance when relevant.
- Key azimuth/elevation, modifier type/size/distance, fill, negative fill, rim, background light.
- CCT/white balance, contrast target, shadow direction/softness/density, highlight roll-off.
- Reflection control, polarization where useful, transparent/translucent/metallic/gloss/matte handling.
- Dark/deeper skin-tone metering/highlight protection/separation; preserve natural tone and texture.
- Color management and product-color fidelity.
- CMF: color/material/finish/texture/reflection/edge treatment.
- Styling, wardrobe, hair/makeup, hand grooming, props and set dressing from audience/culture strategy.

## Creative-language policy
Use positive-first instructions. Plants, water, laboratory language, models, props, animals, nature, texture, still-life and motion are creative vocabulary selected by strategy—not default inclusions and not default exclusions. Explicit blocking language is concentrated on P0 truth/compliance/product-fidelity/current-rule/scope issues.
