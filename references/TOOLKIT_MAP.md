# Deterministic Toolkit Map

The reference repository uses 7 Agent workflows plus deterministic scripts. This system keeps that separation and extends it.

## Reference-compatible core toolkits
1. Market toolkit — normalize exports; capacity/concentration/price/configuration metrics.
2. Product/Pricing toolkit — SKU pricing, contribution, break-even, platform-fee registry.
3. Listing toolkit — title lint and spec/number consistency.
4. Image toolkit — dimensions/aspect/background/contract checks where deterministically measurable.
5. Video toolkit — duration, word budget and subtitle line checks.
6. Advertising toolkit — break-even ROAS/CPC/contribution and funnel metrics.
7. Feedback toolkit — review/feedback aggregate counts and weighted themes after semantic classification.

## Extended toolkits
8. Truth/Claim toolkit — source IDs, claim evidence and conflict checks.
9. Asset/Traceability toolkit — dynamic asset map, handoff and source/claim references.
10. Experiment toolkit — baseline/variant deltas and causal-test bookkeeping.
11. Platform toolkit — adapter capability/freshness validation.
12. Capability/Machine-audit toolkit — verify the release did not silently lose required capabilities.
