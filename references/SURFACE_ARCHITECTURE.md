# Commerce Surface Architecture

Assets are planned by surface, market, locale and journey role rather than by a single gallery template.

Supported surfaces include when relevant:
- Search / Listing card
- PDP / Gallery
- Longform / A+ / rich description
- Shop Page / brand page
- Shoppable Photos
- Paid Ads / retargeting
- Short Video / product video
- Creator / Affiliate / UGC
- Social organic
- Live / live-shopping support
- FAQ / customer service / returns-prevention
- Email / CRM / retention

Each surface record includes:
`surface_id, platform, market, locale, journey_stage, entry_state, exit_state, purchase_barrier, consumer_question, asset_ids, information_gain, handoff, metric_hypothesis`.
