# CBCC Human Workspace Theme Contract v0.6.6

## 定义
`index.html` 是面向项目使用者的完整正式交付，也是一个自包含离线 SaaS Workspace。它不是长篇 Editorial Report、文件浏览器、Markdown 聚合器或目录页。

## 信息架构权威
主导航按用户任务组织：
- 工作台
- 产品事实
- 市场 / 人群
- 上架中心
- 策略中心
- 视觉 / 摄影
- 资产中心
- 提示词工作台
- 风险 / 合规
- 来源 / 真源
- 归档

每个业务模块继续拆成任务子页；一次只显示一个工作对象/主题。禁止依靠“左侧锚点 + 一条超长页面”承载完整项目。

## 资产工作区
资产库只用于选择资产；每个资产进入自己的详情路由，再切换：
- 资产概览
- 策划与决策
- 画面与版式
- 摄影 / CMF
- 文案
- 生成与生产
- 合同 / QA / 来源

Human Design Card 是资产默认第一屏；原始 YAML/JSON 不得成为默认人类视图。

## 中文优先
- 默认交付语言 `zh-CN`；用户明确指定时覆盖。
- 目标市场文案按目标语言保留原文。
- 非中文目标文案必须在同一工作区提供中文释义 / 用途。
- 内部机器术语/状态/规则在主工作区以中文为主要显示层；原始键只在归档保留。
- 中文规范生产提示词必须存在；英文/目标模型提示词是执行载体，不是唯一交付。

## 视觉系统
- 视觉主题优先从当前项目 CMF / HEX 派生；不得给所有品类强制同一品牌色。
- 保持产品级 SaaS 信息密度：任务卡、状态、对象列表、子导航、Copy action、独立资产页。
- PC 为侧边工作区导航 + 局部任务导航；移动端主导航/子导航可横向滑动，内容单列。
- 核心阅读离线可用，不依赖外部 CDN。
- 支持打印/PDF，但打印版是 Workspace 的投影，不反过来主导网页结构。

## 完整内容与源文件
所有人类可读内容仍完整存在 HTML 内。MD / JSON / TXT / per-asset 文件继续作为编辑、机器、版本和审计真源；用户无需打开这些文件才能理解或执行项目。
