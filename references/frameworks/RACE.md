# RACE Framework

RACE is the process backbone, not a decorative table.

## Research
Product truth, market, platform, region, audience, race/ethnicity, culture, competitors, keywords, claims, evidence.

## Action
STP, JTBD, positioning, value proposition, information hierarchy, listing architecture, visual strategy, asset map, budget and production priorities.

## Communication
Listing/PDP, search, shop page, creator/UGC, short video, ads, live, social, CRM/private channels where applicable.

## Evaluation
Baseline, attribution, CTR/PDP/ATC/CVR/CPA/ROAS as applicable, review/return misunderstanding, A/B tests, causal iteration.

Every platform content matrix row must include a RACE stage.
