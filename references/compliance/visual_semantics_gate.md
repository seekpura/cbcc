# Visual Semantics Gate

Plants, water, laboratory motifs, models and props are **not globally banned**. They are gated because visuals can create claims.

## Gate fields
- strategic_relevance
- truth_support
- claim_implication
- culture_fit
- platform_fit
- asset_approval

## Decisions
- ALLOW: truthful and strategically approved.
- ALLOW_AS_ABSTRACT: metaphor is clearly non-literal and does not imply unsupported product behavior.
- CONDITIONAL: needs evidence/source/placement clarification.
- BLOCK: creates unsupported or prohibited implication.

Examples:
- Plant: ALLOW if verified ingredient/brand story; BLOCK if it implies ingredient not present.
- Water: ALLOW_AS_ABSTRACT for hydration ambience if not shown as actual product behavior; BLOCK when it implies waterproofing.
- Laboratory: ALLOW for real technical/ingredient education; BLOCK if it fabricates clinical testing/certification.
- Model: ALLOW when casting and use scenario are strategic; BLOCK only for mismatch, unsupported result depiction, platform/culture issue, or unapproved use.
- Props: ALLOW when approved and non-misleading; BLOCK if they look like included accessories when they are not.
